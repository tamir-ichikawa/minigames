# STAR BOUNCE：銀河のおやつ争奪戦

Web / Phaser 3 / TypeScript。2026-10-15時点のルールです。

```sh
npm run dev:star-bounce
```

http://127.0.0.1:4174/ を開く。TSの変更は自動ビルドされるのでブラウザーを再読み込みする。HTML/CSS/素材の変更もローカル出力へコピーする。生成物はこのフォルダの `.build/`（Git対象外）。ミニゲーム集の `npm run build` では `dist/sample_game/STAR_BOUNCE/` に素材と単独版を出力し、GitHub Pagesにも配信する。

## ルール

- GOOD「銀河のおやつ配達団」／DARK「銀河のおやつ独占計画」、各3章。相手と相談するためのラリーで、倒す・殺す演出は使わない。
- 各章は3ゴールでクリア。味方のHPは5色の星。下へ落とすと1つ減り、0でゲームオーバー。次の章へ進むと1回復（最大5）。
- HP・合計得点を次の章へ引き継ぎ、章のゴール数と必殺ゲージはリセット。
- 通常返球10点、ゴール100点。飛来物はファルコン号350点、戦闘機150点、輸送船250点、探査艇200点、護衛艦300点。ボーナスは当てると反射し、一度だけ得点。
- 5回返球でゲージ100%（トコリは4回）。盤面内の縦ゲージ下の半透明な丸ボタン、またはSpaceで発動。発動中の重ねがけは不可。
- プレイ領域の外の専用パッドを左右にドラッグして操作（指を置いた瞬間にバーが飛ばない相対操作）。マウス／← →／A Dで操作。最高得点はGOOD/DARK・難易度別に保存（ストーリー試作の難易度導入前の記録はイージーへ引き継ぐ。旧クラシック版とは別保存）。ストーリー途中の中断セーブは未実装。
- 全3章の結末のあと、同じ相棒で無限ラリーへ進める。HP5で開始し、得点を引き継ぐ。
- 相手と味方を右上・左下に小さく表示し、バーは上端・下端から28ゲーム単位の位置。プレイ領域は縦長を維持し、残りの画面高に合わせて伸縮。短い横画面では操作パッドを右側へ移動し、盤面を指で覆わない。
- タブを離れると一時停止。再開操作で続行。キャラ選び直しは確認してから旅をリセット。

| GOOD | ポポ | バー幅118、移動460 | もふもふワイド：6秒間、幅+54 |

## 画面と操作

- ページ全体を `100dvh` に収め、選択・会話・結果画面も高さに応じて縮小する。ページスクロールは不要。画面が極端に小さい場合は文字も縮小される。
- 縦画面では操作パッドを盤面の下へ、短い横画面では右へ置く。ドラッグ中に指がパッドの外へ出ても追従し、指を離す／中断する／一時停止する時に解除。
- バーはプレイ領域の上下端近く、キャラは角の小さな枠。白背景を外した透過シートで表示。
- 必殺技と左右矢印の下段は廃止。下部はドラッグ専用パッドのみ。縦ゲージと丸ボタンは盤面内の右側で半透明表示。
- キャラは各6フレーム（待機2、返球、喜び、落ち込み、必殺技）。飛来物は5機種、各4フレームのエンジン光アニメーション。星の瞬き、ボールの軌跡、返球・得点・ミス・必殺技のパーティクルを追加。
- 背景は対戦相手のホームに切り替える。章番号とは独立し、同じ相手は同じ場所になる。
- 遠景の一枚絵／中景のループする光と瞬き／手前の透過装飾の3層。遠景と惑星・建物は固定し、中景の淡い光だけをゆっくり流す。手前を通過する装飾は廃止。葉や雲だけがごくわずかに揺れ、バー操作による背景の追従は行わない。森は蛍、カフェや海辺は柔らかい光など、場所に合わせた演出。
- 上部「設定」→「軽量・一枚絵」で背景の描画を画像1個に減らす。中景・手前のオブジェクトとDARKの歪み用シェーダーを破棄し、背景更新を停止。ゲーム・キャラ・バーは継続する。画像の先読みは共通なのでダウンロード量を減らす設定ではない。
- 設定中はプレイを止め、閉じると元の状態へ戻る。背景だけを差し替えるのでHP・得点・球・ゲージは保持。表示設定はプラットフォームの保存機能に記録。
- バーは7人別の装飾（リボン、真珠、羽、葉、牙、三日月、火花）。GOODは柔らかい光の粒、DARKは細かい放電。返球時には光の輪が広がる。当たり判定は光ではなく従来のバー本体。
- DARKを選んだプレイヤーの球には、背景だけを透明に屈折させる軌跡を追加。WebGLの局所的なシェーダーで、球・バー・得点表示には適用しない。Canvasでは薄い波紋の代替表現。軽量表示は波紋のみ。
- 返球音は「低音ブン」「やわらかい風」「重いヴォン」「短いブッ」「これまでの音」の5候補。暫定初期値は低音ブン。上部「設定」→「返球音を選ぶ」で候補を押すと試聴して採用する。GOOD/DARKの比較ボタンもある。DARKは低め、相手の返球は小音量。
- 試聴は明示的なボタン操作で鳴らし、ゲームの音OFF中・一時停止中でも再生できる。新たな試聴・タブ切替・閉じる・画面を離れる・終了で前の試聴を止める。ゲーム中の音は従来どおり音ON/OFFに従う。候補は `star-bounce-story:swing` に保存。

## 難易度（暫定バランス）

初期選択は「通常」。すべて得点・失点で球速とラリー数を戻す。物体ボーナスでは速度を戻さない。ステージ進行による初速上昇は残す。

| 難易度 | 初速の縦成分 | 返球ごとの加速 | 上限 | 相手 |
| --- | ---: | ---: | ---: | --- |
| イージー | 270 | +8 | 485 | これまでの追跡AI |
| 通常 | 300 | +22 | 950 | 壁反射を先読み。速度480を超えると狙いがずれ始める |
| 難しい | 330 | +28 | 1250 | 移動と判断が速く、速度730まで精度を保つ |

相手は瞬間移動せず、通常・難しいでも必ずミスするとは限らない。数値は `DIFFICULTIES` で調整できる。

## 編集場所

- `content.ts`：7人の性能・素材対応、両サイドの台詞・3章・エンディング。
- `model.ts`：固定時間刻みのラリー、衝突、必殺技、章進行。DOMや保存処理に依存しない。
- `flights.ts`：5機種の出現順、直進・斜め・波状・弧の飛行、向き、リサイズ時の経路補正。最初はファルコン号。最大2機で、各機の飛行経路は出現ごとに変化する。
- `scene.ts`：Phaserの描画、レスポンシブ配置、キャラ選択・会話UI、入力、演出。
- `index.ts`：既存ミニゲーム集と同じ `GameModule` の接続部分。起動／停止／再開／終了。
- `main.ts`：ローカル版のWebプラットフォーム接続。保存は既存と異なる `star-bounce-story:*` キー。
- `style.css`：単独版と共通プレイヤーで使う画面UI。
- `stages.ts`：相手ごとの背景・色・装飾・バーのデザインを登録。
- `backdrop.ts`：3層背景／軽量一枚絵の生成・更新・破棄。
- `dark-wake.ts`：背景に限定した屈折シェーダー。軌跡の8地点だけを変形。
- `settings.ts` / `swing-presets.json`：表示・音の選択UI、試聴、音の候補と合成パラメーター。
- `bars.ts`：7種のバー、GOOD/DARKの通常オーラと返球演出。
- `sozai/`：ローカルに保持する提供原本。配布物とGitには含めない。
- `assets/`：透過キャラシート2枚、飛来物シート2枚、背景6枚、背景用透過装飾シート1枚。
- `asset-prompts.json` / `background-prompts.json` / `flight-prompts.json`：built-in image_genで使用した生成・透過編集プロンプトと保存先。
- `audio.mjs`：独自チャイムと返球音を波形合成。ビルド時に `.build/assets/chime-*.wav` / `swing-{候補ID}-{good|dark}.wav` へ出力。映画・ゲームの録音素材は使わない。

## ミニゲーム集との接続

既存の `games/pong/index.ts` が `createGame({managed:true})` を呼び出す。ゲームID `pong` と公開URL `play.html?game=pong` を保ってストーリー版へ更新する。ホストの停止・再開・消音・リセット・終了に接続し、ゲーム内で先に停止していた場合はホストの再開だけで勝手に進めない。

通常ビルドの素材出力は `build.mjs` が担当し、未採用の `sozai/` と旧ボーナスシートを除外する。共通プレイヤー用スタイルは `.sb-shell` 内に限定する。ResizeObserverが画面・親コンテナ・操作パッドの表示変更を追跡し、Phaserの表示サイズを更新する。

## スプライトの配置

`good-sheet.png` は6列×4行（ポポ、メリー、トコリ、モックル）、`dark-sheet.png` は6列×3行（クロ、ネネコ、アカネ）。列は待機、まばたき、返球、喜び、落ち込み、必殺技の順。各行をPhaser Animationで使用。GOODの小鳥と森のキャラは境界に隣のキャラが入らないよう、小鳥の行をY=512〜742/1024、森のキャラをY=746〜1024/1024で切り出す。選択・会話の画像も同じフレームから表示。

`fleet-sheet.png` は4列×4行で、戦闘機・輸送船・探査艇・護衛艦の順。`falcon-sheet.png` は2列×2行で、提供された三面図 `sozai/28FB2514-9E4D-4E93-8F84-8C97D0E64FC5.png` の上面図から派生。いずれも右向き4コマのエンジン光アニメーション。ファルコン号はコマごとに機体中心のピボットを補正し、発光中に船体が上下へずれないようにする。飛行中は機首を速度ベクトルに向け、同じ角度に回した楕円でボールと判定する。表示寸法・機体中心・判定・得点は `BONUSES` で管理。旧 `bonus-sheet.png` は原本として残すが、この試作の飛来物には使わない。

ファルコン号はユーザー提供素材を使ったローカル試作。追加の4機は内蔵画像生成で制作。これらは公開可否・権利確認を済ませたことを意味しない。生成・編集の指定内容は `flight-prompts.json` に記録する。
