# スプライト制作記録 v2

2026-10-15 / 内蔵 image_gen による制作。旧版は [SPRITES-v1.md](SPRITES-v1.md)。

ヤギと狐の頭身を約3頭身に揃え、上下・斜めの絵柄を追加。各シートは10列で、ヤギは4行（小隊長・斥候・衛生兵・歩兵）、狐は6行（橙の士官・橙の歩兵・銀・紫・茶・砂色）。

左・左上・左下は左右反転。合計500コマ。列順は待機、歩行A、歩行B、構え、発射、被弾、被弾から戻る、膝をつく、崩れる、伏せる。狐の右／右下向きは最終静止に閉眼した第9列を選ぶ。

`src/sprites.js` は透明な余白を探して行・列を切り出し、基準の立ち姿の高さと足元を揃えて128pxセルへ配置する。元PNGの絵柄・縦横比は変えない。アクションと方向に対応するコマを選択し、移動射撃は歩行と発射のコマを交互に使う。
