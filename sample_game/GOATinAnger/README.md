# GOAT in ANGER — クローバー小隊

Phaser 3 + Viteで制作した、ヤギ対狐の見下ろし型シューティングです。

## ミニゲームプロジェクトとの統合

本体・素材は `sample_game/GOATinAnger/` にあります。親プロジェクトで以下を実行すると、一覧の「GOAT in ANGER」から起動できます。

```sh
npm run dev
# http://127.0.0.1:4173/play.html?game=goatinanger
```

`games/goatinanger/` は一覧登録と共通プレイヤーへの接続です。親の `npm run build` でこのゲームもビルドされます。ゲーム本体はiframe内に隔離し、共通の停止・再開・リセット・終了・ミュート・スコア表示に接続しています。独立起動とサブディレクトリでの配信にも対応します。

単独開発の初回はこのフォルダで `npm ci` を実行します。親フォルダから単独開発する場合は `npm run dev:goatinanger`、ルールテストは `npm run test:goatinanger` を使用します。

## 単独起動

Node.js 20.19以上、または22.12以上を使用してください。

```sh
npm install
npm run dev
```

ターミナルに表示されるURL（通常は http://127.0.0.1:5173/ ）をブラウザで開き、「作戦を開始」を押します。`index.html`を直接ダブルクリックせず、開発サーバー経由で開いてください。

## 操作

| 入力 | 動作 |
| --- | --- |
| 携帯の左側の方向パッド | 上下左右へ移動し、向きを変更 |
| 携帯の右側の「射撃」ボタン | 向いている方向へ射撃。長押しで連射 |
| WASD / 矢印キー | 移動・向き変更。2キー同時で斜め方向 |
| Space | 射撃。長押しで連射 |
| 移動と射撃を同時押し | 移動しながら射撃 |
| 指・キーを離す | 対応する移動・射撃を停止 |
| P / 一時停止ボタン / Esc | 一時停止（Pで再開） |
| Enter | 作戦開始・再開・再挑戦 |
| R | 結果画面から再挑戦 |

移動と射撃は別操作です。入力がなければ発射しません。開始時は北を向き、移動すると射撃方向も変わります。移動を離しても向きは維持するため、その場で射撃できます。携帯・タッチ対応端末では左に上下左右の方向パッド、右に射撃ボタンが表示され、2本の指で同時操作できます。ドラッグ移動は廃止しました。斜め移動でも速度は増えません。効果音は初期オフで、SOUNDボタンで切り替えます。別タブへ移ると一時停止します。

## ゲーム内容

- ヤギ4人から1人を選択。移動速度・連射速度・体力が異なります。
- 表示領域は540 × 960（9:16）、マップは540 × 2880。プレイヤーの北への移動にカメラが追従します。
- 南から「森林入口 → 渓谷の橋 → 北の前哨地」の3区間。道・樹木・川・木橋・施設・遮蔽物を区間ごとに配置しています。
- 各区間で6体 → 8体 → 10体の敵が画面上端から順次進入。出現間隔は1.7秒 → 1.5秒 → 1.3秒。未出現分も残数に含みます。
- 戦いながら前へ進めますが、未制圧の区間の北端は突破できません。敵を全滅させると制限が解除され、**次の区間へ実際に移動した時点**で次の敵襲が始まります。待つだけでは次の敵襲は始まりません。
- 全24体を倒し、北端の撤収地点へ入るとクリアです。
- プレイヤーの弾の射程は320px、敵は440px。木の幹・木箱・土のうは移動と弾丸を遮ります。
- 敵は登場中から木箱・土のう・木の幹を迂回します。射線が遮られる場合も回り込み、狭い通路で敵同士が押し合って停止しないようにしています。
- 被弾後は1.3秒無敵。5体撃破ごとに回復アイテム（体力+2）が出ます。
- 敵1体100点、クリア時は残り体力 × 200点を加算します。

## キャラクターとアニメーション

ヤギ4種類と狐6種類を約3頭身のゲーム用スプライトへ統一しました。隊員選択も同じスプライトの正面コマを使います。読み込み中は旧画像を表示せず「素材を読み込み中…」を表示し、準備ができると隊員選択と開始を有効にします。原画とv1スプライトは保存しています。

- 右・上・下・右上・右下の5方向を専用の透過PNGで制作。左・左上・左下は対応画像を反転し、8方向で描画します。
- 各キャラクター各方向に10コマ、10枚のシートで計500コマ。待機・歩行・射撃・移動射撃・被弾・倒れる動きを状態に応じて選びます。
- 被弾は身を引く→戻るコマ、倒れる動きは膝をつく→崩れる→伏せるコマを再生します。死亡の最終コマは固定し、敵は1.2秒後に消えます。
- 勝敗時は0.85秒の演出後に結果を表示。一時停止ではコマ送りも止まります。

画像ファイル一覧、方向・コマ対応、内蔵image_genで使用した生成プロンプトは [SPRITES.md](SPRITES.md) を参照。

## 全画面・リサイズ

縦長のゲーム表示領域と操作UIを、利用できる画面領域へ比率を保って収めます。長いマップはスクロールで進行し、マップ全体を一度に縮小表示しません。横画面やPCでは余白を許容し、表示領域の切り取り・引き伸ばしはしません。

画面回転、ブラウザーの高さ変更、全画面の切り替え、埋め込み先のサイズ変更でも、進行・スコア・座標・カメラ位置を維持します。隊員選択も画面内にあり、ページのスクロールは不要です。共通方針は親の `AGENTS.md` と `docs/adding-games.md` に記録しています。

## 構成・調整箇所

- `src/main.js` — Phaserシーン、地形、敵AI、射撃、当たり判定、画面UI
- `src/rules.js` — 射程、隊員能力、敵襲の数・出現間隔・上端レーン、移動ベクトル
- `src/navigation.js` — 体の大きさを考慮した障害物の迂回経路・射線判定
- `src/sprites.js` — スプライト領域・足元合わせ・アクション別コマ送り
- `src/style.css` — ページの見た目・画面幅への対応
- `public/assets/` — 使用イラスト
- `tests/rules.test.js` — 射程・移動などの単体テスト
- `tests/browser-checks.js` — 実際のPhaser物理エンジンを使う開発用の統合テスト

## 確認・ビルド

```sh
npm test
npm run build
npm run preview
```

開発サーバーの `/?qa` を開くと、移動、射撃、射程、被弾、遮蔽物、一時停止、撃破、敵襲、撤収、再挑戦の統合テストを実行し、結果を表示します。QAコードは本番ビルドに含まれません。

親フォルダで `npm run build` 後、 `node tests/goatinanger-browser.mjs` を実行すると、移動と射撃の別操作、8方向・被弾／死亡のコマ送り、区間突破、縦スクロール、7つのアニメーション状態、画面サイズ変更、全画面切り替え、共通プレイヤーでの停止・再開・リセットも検証できます。スクリーンショットは `.test-output/goatinanger/` に出力します。

`node tests/goatinanger-navigation-browser.mjs`（親フォルダから実行）では、木箱・土のうに接触する配置での迂回と停止射撃・移動射撃・タッチの同時押しを検証します。

`npm run build`で`dist/`に静的ファイルを生成します。Phaser本体を含むため、初期バンドルサイズについてViteの警告が出ますが、ビルドは成功します。親プロジェクトではGitHub Actionsから他のゲームと一緒にGitHub Pagesへ配信します。

使用技術: [Phaser公式ドキュメント](https://docs.phaser.io/phaser/getting-started/installation)
