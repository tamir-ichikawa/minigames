# マロの大冒険

Phaser 3.90 / TypeScript による10ステージの試作です。斉藤さんの原画を使い、栞音とはぐれたマロがコテージへ戻る短い冒険を遊べます。

## 起動

リポジトリのルートで実行します。

```sh
npm run dev:maro        # 単独プレビュー http://127.0.0.1:4175/
npm run build:maro      # 単独出力: このフォルダの .build/
npm run build          # ゲーム一覧・共通プレイヤーを含む配布ビルド
npm run preview        # http://127.0.0.1:4173/
```

配布先URLは `sample_game/maro-adventure/`、共通プレイヤーは `play.html?game=maro-adventure` です。ソースの `index.html` を直接開くのではなく、上記のサーバーを使用してください。生成された `dist/` は従来どおり配布できます。

## 操作とルール

- 画面内の好きな位置からドラッグすると、その移動量に合わせてマロが動きます。タップした場所へ瞬間移動はしません。
- マウス／指を離すと停止。矢印キーまたはWASDでも移動できます。
- 足元の白い輪が当たり判定の目印。道の外へ出たり犬に接触するとミスになります。
- 「休憩」で全体を一時停止。単独版はEscapeでも切替。共通プレイヤーではEscapeが共通の停止操作になります。
- 緑の旗がチェックポイント。ミス後は約1.15秒で復帰します。残機・制限時間はありません。
- 各ステージ3枚、合計30枚のおさかなメダルを任意で集められます。ミスしても回収済みメダルは保持します。
- 最終クリア時にミス回数が少ない記録を保存。同数ならタイムの短い記録を優先します。通常操作でタイトルへ戻ると進行はリセットされます。

## ステージ

1. **はぐれた森の小道**：道に沿う操作と任意の寄り道。
2. **ナックルの木橋**：往復するナックルを横の待避所でやり過ごします。
3. **キャンプ場の抜け道**：最初のスパイク追跡と猫専用の穴。
4. **せせらぎの細道**：川沿いの細い折り返し。
5. **こもれびの崖道**：斜めに進む曲がり角。
6. **倒木のトンネル**：森で再びスパイクを振り切る。
7. **ナックルの見回り道**：横に巡回する犬と上下の待避所。
8. **花畑のまわり道**：引き返す区間のある細い迷路。
9. **夕暮れのキャンプ場**：大きな折り返しを走り、灯りを目指す。
10. **栞音の待つコテージ**：最後の追跡を抜け、栞音と再会。

**原画の左の細身の犬がスパイク、右の体格の大きい犬がナックルです。**

## ファイル

- `model.ts`：論理座標、道、判定、巡回・追跡、チェックポイント、ステージ進行。
- `art.ts`：道の判定と共通の座標に基づく森・橋・キャンプ場の描画。
- `animation.ts`：3匹×4方向×8コマのフレーム範囲、足元基準の描画と移動量に連動する歩行。
- `scene.ts`：Phaser表示、ドラッグ・キー入力、画面遷移、効果音、記録。
- `index.ts`：単独／共通プレイヤー共通の起動・停止・リセット・破棄、画面サイズ対応。
- `style.css`：タイトル、ヒント、結果、スマホ用レイアウト。
- `main.ts` / `build.mjs`：単独起動と配布出力。
- `assets/`：実行時素材。生成経緯は `assets/README.md`。
- `素材/`：受領した原画。変更していません。

画面は720×820の論理座標を保ち、親要素のResizeObserverで縦横比を維持してフィットします。画面回転・高さ変更・全画面でモデルの位置や進行を初期化しません。入力は解除するため、リサイズ後は改めてドラッグしてください。

## 検証

```sh
npm run build
npm run test:maro
npm test
```

`test:maro` のブラウザ検証にはChromeまたはPlaywright Chromiumが必要です。macOSでは通常のGoogle Chromeを検出します。別の場所にある場合は `CHROME_PATH` を設定してください。

ブラウザ検証は、マウス操作で全10ステージと全メダル収集を完走し、タッチ操作、ミスと復帰、停止と再開、記録保存、縦横リサイズ、全画面、共通プレイヤー、破棄後のcanvas除去を確認します。結果は `.test-output/maro-adventure/` に出力します。

## 歩行と方向（改修版）

- 各キャラクターに正面・左・右・後ろの8コマ歩行。右向きは左向きシートの鏡像で、方向間の画風と体格を統一しています。
- 1歩行周期は実移動56px。ごく小さな移動も積算し、入力の隙間や停止中にコマを巻き戻しません。
- 別方向へ12px以上進んだら向きを変更。斜めの曖昧な動きや小さな往復では現在の向きを保ちます。
- マロは正面の頭と胴体の比率を調整し、元原画から高解像度のシートを再生成しました。
- スパイクは、マロが穴を越えても現在地を維持し、そこから入口の32px手前まで走って停止。位置を固定値へ移す処理を削除しました。
- 10ステージ・30メダルの記録は `best:v2` に保存。旧3ステージの記録は旧キーに残し、新しい記録と混在させません。

`assets/` にシートと生成プロンプトを保存しています。生成PNGは変更せず、読み込み時に各キャラクターの輪郭を分離してフレーム化します。背景の透明度を保ち、隣のコマの鼻・尻尾の映り込みを防ぎます。

`previews/maro-playthrough.webm` と `previews/maro-walking.gif` は以前の3ステージ版の参考映像です。最新版の録画はビルド後に `MARO_RECORD=1 node tests/maro-adventure-browser.mjs` で再生成できます。
