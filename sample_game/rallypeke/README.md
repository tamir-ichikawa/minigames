# ラリーぺけ（RALLY-PEKE）

懐かしゲームシリーズ 第4弾。広い迷路を車で走りまわって旗を集める、ラリーXのオマージュゲームです。
迷路・車・アイテム・音はすべてオリジナルです。迷路はステージごとに毎回ちがう形になります。

## 遊び方
- パソコン：`←` `↑` `↓` `→`（または `W` `A` `S` `D`）で曲がる、`Space`（または `Z` `X`）でシャボン玉、`P` で一時停止、`Esc` でタイトルに戻る
- スマホ：画面をスワイプするか、画面下の十字ボタンで曲がる。🫧ボタンでシャボン玉
- 迷路のどこかにある「ぺけ旗」を10本ぜんぶ集めたらステージクリア
- 車は止まらずに走り続けます。かべに当たると自動で曲がります
- ジャマカーやコーンにぶつかると残機が1つ減ります。残機が0になったらゲームオーバー
- 曲がり角の手前で先に押しておくと、角でスムーズに曲がれます

## 特徴
- 自分の車「ぺけ号」はピンク。屋根に白い ✕（ぺけ）マーク
- 敵の「ジャマカー」は紫。むすっとした目つきで追いかけてくる
  - まっすぐ追いかけてくる子、先回りしてくる子、気まぐれな子がいる
- 右下のレーダーで、旗（黄）・ジャマカー（紫）・ぺけ缶（緑）の場所がわかる
- シャボン玉：当たったジャマカーはくるくる回って少し止まる（ガソリンを少し使う。止めると50点）
- ガソリン：走っていると減っていく。空になると車がのろのろになる
- アイテム
  - ぺけ旗：1本目100点、2本目200点…10本目1000点
  - Wはた：取ると、そのステージでこのあと取る旗の点数が全部2倍
  - ぺけ缶：ガソリンが満タンになる
- コーン：道のとちゅうに置いてある。ぶつかるとアウト
- ステージクリアで、のこったガソリンがボーナス点になる
- 次のステージは、ジャマカーとコーンが増えて、ジャマカーが少し速くなる
- 20000点で1UP
- むずかしさを3段階で選べる
- ハイスコアはむずかしさごとに覚えている
- 効果音つき（`🔊` で ON/OFF）

## むずかしさ
- やさしい：ジャマカーがゆっくり、シャボン玉で長く止まる、ガソリン長持ち、残機4
- ふつう：アーケード風、残機3
- むずかしい：ジャマカーが速くて数も多い、コーン多め、ガソリンが早く減る、残機3

## 動作環境
- サーバー不要。ブラウザだけで動きます
- 対応：Chrome、Safari（パソコン・スマホ）
- `rallypeke.html` をブラウザで開くだけでOK
