# ぱっくんまん（PAKKUN-MAN）

懐かしゲームシリーズ 第3弾。迷路のドットを食べていく、パックマンのオマージュゲームです。
迷路・キャラクター・音はすべてオリジナルです。主人公の「ぱっくん」はクリーム色です。

## 遊び方
- パソコン：`←` `↑` `↓` `→`（または `W` `A` `S` `D`）で向きを変える、`P` で一時停止、`Esc` でタイトルに戻る
- スマホ：画面をスワイプするか、画面下の十字ボタンで向きを変える
- 迷路のドットを全部食べたらステージクリア。次のステージは、おばけが少し速くなります
- おばけにさわると残機が1つ減ります。残機が0になったらゲームオーバー
- 曲がり角の手前で先に押しておくと、角でスムーズに曲がれます

## 特徴
- 大きいパワーえさを食べると、おばけが青くなって逆に食べられる（200→400→800→1600点）
- おばけは4ひき。それぞれ動き方がちがう
  - ドキン（赤）：まっすぐ追いかけてくる
  - ニヤリ（ピンク）：先回りしてくる
  - ツンツン（水色）：気まぐれ
  - のんびり（オレンジ）：近づくと逃げていく
- ドットを70個・150個食べると、ボーナスのフルーツが出る（ステージごとに種類と点数が変わる）
- 10000点で1UP
- むずかしさを3段階で選べる
- ハイスコアはむずかしさごとに覚えている
- 効果音つき（`🔊` で ON/OFF）

## むずかしさ
- やさしい：おばけがゆっくり、パワーえさが長く効く、残機4
- ふつう：アーケード風、残機3
- むずかしい：おばけが速い、パワーえさがすぐ切れる、残機3

## 動作環境
- サーバー不要。ブラウザだけで動きます
- 対応：Chrome、Safari（パソコン・スマホ）
- `pakkunman.html` をブラウザで開くだけでOK
