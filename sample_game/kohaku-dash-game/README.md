# コハク便ダッシュ — スプライトシート版

ホッキョクギツネ「コハク」の配達ランナーゲーム。

## ファイル構成

```
kohaku-dash-game/
├── index.html          ← ゲーム本体（ブラウザで開く）
├── kohaku_sprites.png  ← 旧スプライトシート（透明背景）
├── kohaku_sprites-v2.png ← 改良版スプライトシート（透明背景）
└── README.md           ← このファイル
```

## 遊び方

`index.html` をブラウザで開くだけ！

### 操作
- **PC**: ← → キー（または A / D）でレーン移動、スペースで開始
- **スマホ**: 画面の左右タップ

### ルール
- ⭐ 星を拾ってスコアUP（金色の星は2倍ボーナス）
- 📦 箱に当たったら配達終了
- 🔥 5個連続で配達コンボ → 報酬UP
- スピードはスコアに応じて 3.0 → 6.0 に加速

## スプライトシート仕様

`kohaku_sprites-v2.png` — 640×256px、透明背景PNG（ゲーム本体で使用）

| 配置 | フレームサイズ | グリッド |
|------|-------------|---------|
| 5列 × 2行 | 128 × 128 px | 合計10フレーム |

### 1行目（アクション）
| Col 0 | Col 1 | Col 2 | Col 3 | Col 4 |
|-------|-------|-------|-------|-------|
| 待機  | 走る  | ジャンプ | アイテム取得 | （空き） |

### 2行目（表情差分）
| Col 0 | Col 1 | Col 2 | Col 3 | Col 4 |
|-------|-------|-------|-------|-------|
| 通常  | 笑顔  | びっくり | 怒り | おやすみ |

### 読み込み例 (JavaScript)
```js
const FRAME = 128;
// Col=1, Row=0 の「走る」フレームを描画
ctx.drawImage(spriteImg,
  1 * FRAME, 0 * FRAME, FRAME, FRAME,  // ソース切り出し
  x - 40, y - 40, 80, 80               // 描画先
);
```
