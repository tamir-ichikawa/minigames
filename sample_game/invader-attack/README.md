# インベーダーアタック

ブラウザで遊べるスペースインベーダー系シューティングゲームです。

## 遊び方
- パソコン：`←` `→`（または `A` `D`）で移動、`Space` で発射、`P` で一時停止、`Esc` でタイトルに戻る
- スマホ：画面下の `◀` `▶` で移動、`発射` ボタンで撃つ（押しっぱなしで連射）
- インベーダーを全部やっつけると、次のウェーブに進みます
- 撃たれると残機が1つ減ります。残機が0になるか、インベーダーが下まで来たらゲームオーバー

## 特徴
- インベーダーは3種類（10点・20点・30点）
- トーチカ（緑の盾）は弾が当たるとだんだん欠ける
- UFOがときどき上を横切り、当てると50〜300点のボーナス
- 1500点で1UP
- むずかしさを3段階で選べる
- ハイスコアはむずかしさごとに覚えている
- 行進の音などの効果音つき（`🔊` で ON/OFF）

## むずかしさ
- やさしい：インベーダー32体、残機4、弾は2発まで同時、動きも敵の弾もゆっくり
- ふつう：インベーダー55体、残機3、弾1発ずつ、アーケード風
- むずかしい：インベーダー55体、残機3、速くて敵の弾も多い

## 動作環境
- サーバー不要。ブラウザだけで動きます
- 対応：Chrome、Safari（パソコン・スマホ）
- `invader-attack.html` をブラウザで開くだけでOK

## ミニゲーム集での公開

`games/invader-attack/manifest.json` で一覧登録し、`play.html?game=invader-attack` から起動できます。配布ビルドには単独HTMLも含みます。共通プレイヤーの停止・再開・消音・再起動と得点表示に対応し、縦横の画面変更や埋め込み時にもゲームと操作ボタンを表示領域内に保ちます。進行中の位置・得点はリサイズで変わりません。

`node tests/added-games-browser.mjs` で、3難易度、移動と射撃、ゲームオーバー／再挑戦、停止、画面回転、全画面、共通プレイヤーを確認します（事前に `npm run build`）。
