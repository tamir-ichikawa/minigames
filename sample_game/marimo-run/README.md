# ぱくぱく！まりもラン

クリックだけで遊べる、強制横スクロール形式のブラウザゲームです。

## 遊び方

- クリック／タップ：目の前の敵を食べる
- Spaceキー：一時停止／再開
- 敵に触れるとゲームオーバー

地上、空中、画面奥から次々と迫る敵を食べて、ハイスコアを目指します。

## ローカルで遊ぶ

`index.html` をダブルクリックしてください。サーバーやインストール作業は不要です。

## GitHub Pages

このリポジトリは外部ライブラリを使わない静的サイトです。GitHub Pagesの公開元をリポジトリのルートに設定すると、そのままゲームとして公開できます。
