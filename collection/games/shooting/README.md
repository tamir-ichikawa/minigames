# ASTRA PATROL / umemura fleet update

静的HTML・Canvasのゲームです。公開先のパスは従来どおり `collection/games/shooting/`。
`index.html` から分離した `game.js` と各モジュールを読み込みます。npmビルドは不要。

## 遊び方・確認

ゲームフォルダをHTTPで配信してください。

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory collection/games/shooting
```

- `/`：自機選択 → 通常プレイ。矢印/WASDで移動、Space/Zで発射。マウス・タッチはドラッグ中に自動発射。
- `/?inspect-player`：3自機の噴射口・アルファ衝突判定・5段階の傾きを拡大確認。
- `/?inspect-fleet`：27機のシート、18専用武器、5爆発、回帰テスト。
- `/?boss=1` ～ `/?boss=6`：選択した自機でボス単体練習。ハイスコアには保存しません。

## 自機

| 機体 | HP | 速度（px / 60Hz tick） | 初期武器 | 当たり判定 |
|---|---:|---:|---|---|
| STANDARD（青） | 3 | 4.8 | 標準弾 | 中心の半径8pxの円 |
| SPEED（赤） | 3 | 5.8 | 貫通レーザー | 中心の半径5pxの円・最小 |
| POWER（黄） | 4 | 3.9 | 追尾ミサイル | 中心の半径10pxの円 |

武器変更と機体選択は独立。選択はローカルに保存。撃墜後は再出撃・機体選び直しが可能です。
全27機に5フレーム（左 / 弱い左 / 中央 / 弱い右 / 右）のPNGシートを用意。
元の絵をアフィン変換し、片側の陰影を追加した2Dバンク表現です。別角度の手描き絵ではありません。
透明余白を除いたフレーム・ピボット・噴射口を一緒に変換します。敵への命中判定にはこの輪郭を使用。
自機だけは遊びやすさを優先した小さな円形判定で、翼・噴射炎への接触では被弾しません。
判定円は画面倍率に追従し、傾いても中心・半径が変わりません。ゲーム中は薄い輪と中心点を表示します。
設定変更は `fleet-data.js` の `players[].hitRadius` で行えます（画像の再ビルドは不要）。

## ボスと難易度

6ボスのHPは順に **360 / 440 / 520 / 600 / 700 / 820**。
弾速を概ね1.5～2.0px/tickに抑え、0.9秒の予告、約4秒の攻撃周期と休止時間を設定。
HP 66%・33%で段階変化。最後の段階は追加予告後に追撃します。
6ボスにも扇状・レーン・リング・双翼ランス・蛇行・星形の固有攻撃を割り当てています。
貫通レーザーは同じ弾から同じ相手へ12tick以内に再ダメージを与えません。
ボス撃破時は敵弾を消去し、自機HPを1回復します。

初期武器で最初の移動ボスを追従する検証（被弾無効・アイテムなし）：
STANDARD 約24.5秒 / SPEED 約28.0秒 / POWER 約15.7秒。
これは命中率の高い自動ベンチで、実プレイヤーのクリア時間を保証するものではありません。
ゲーム進行は固定60Hz。非アクティブ時は一時停止し、復帰時の早送りを防ぎます。

ブラウザ検証：図鑑の190項目、自機確認の27項目すべてPASS。
通常プレイで機体選択・ドラッグ移動・発射、新ボスでHP・予告射線の表示を確認。

## アセットと再生成

- `sprites/atlases/umemura3.png`, `umemura4.png`：参照イラストから背景抽出した透明アトラス。
- `sprites/fleet/`：自機3・敵18・ボス6の切り抜きPNG。
- `sprites/sheets/`：27枚の5フレーム機体シート、5枚の8フレーム爆発シート、manifest.json。
- `sprite-manifest.js`：ブラウザ用の同一マニフェスト（再生成されます）。
- `fleet-data.js`：画像対応、機体性能、噴射口、ボスHP。
- `enemy-attacks.js`：18敵機・6ボスの攻撃パターンと弾の描画。
- `explosions.js`：火炎 / プラズマ / イオン / 装甲破片 / 重力ノヴァ。

元イラストは `sample_game/ASTRA_PATROL_v5/astra patrol.umemura3.png` と `astra patrol.umemura4.png` を変更せず保存。
背景抽出には内蔵imagegenを使用。プロンプトは `checks/asset-prompts.md` に記録しています。
フレームのパッキング・傾き・爆発はCanvasによる決定的な生成です。

画像定義を変更した時だけ、Node.jsと `@napi-rs/canvas` のある環境でリポジトリルートから再生成：

```sh
NODE_PATH=/path/to/node_modules node scripts/build-astra-assets.cjs
```

ゲーム実行にNode.jsやCanvasライブラリのインストールは不要。生成済みPNGとJSをそのまま配信できます。
