# BALL＆PIT

梅村さんとの城塞PIT試作を、ミニゲーム共通プレイヤー用に組み込んだゲームです。通常3ウェーブと守護ゴーレム戦、反射・貫通、EXPと強化選択、球の回収、クリア／敗北とリトライを収録しています。

## 起動

ルートで `npm ci`、`npm run dev` を実行し、一覧の「BALL＆PIT」を選びます。直接URLは `play.html?game=ballpit`。ゲーム登録は `manifest.json` から自動検出され、通常ビルド・GitHub Pages公開に含まれます。試作フォルダや独自ビルドへの依存はありません。

## 操作

- A / D または ← / →：左右移動
- マウスで照準、左クリック長押し：連射
- タッチ：下の矢印で移動しながら戦場を長押しして射撃
- 強化カード：レベルアップ時に1つ選択
- 休憩 / 共通プレイヤーの一時停止 / Escape：停止と再開
- ⛶：任意の全画面表示（対応ブラウザー）

タイトルで初期球数を3・5・8球から選べます。初期球数と最高撃破数を共通ストレージに保存し、共通プレイヤーに撃破数を報告します。音は共通のミュート設定に従います。開始画面に戻っても記録は維持します。

## 構成と画面対応

`model.ts` と `data.ts` は描画から独立した戦闘ルール、`scene.ts` はPhaser描画と入力、`index.ts` は共通ライフサイクルとUIです。スタイルはShadow DOM内に限定しています。

論理戦場は560×660のまま、ResizeObserverで利用可能な領域に等比で収めます。リサイズ・画面回転・全画面切替では戦闘状態を初期化しません。終了時にはPhaser・入力・音声・ResizeObserver・DOMを解放します。

## 素材

`assets/` は試作の `sozai/runtime/` から引き継いだスプライト2枚とPhaserアトラスです。豚・敵・EXP・被弾・撃破・ボス演出の144コマ定義を含みます。2026-10-15に試作の設計資料を参照して生成された仮素材で、背景・城門はPhaser Graphicsで描画しています。原資料は公開版の動作に不要です。

## 検証

```sh
npm run build
node --test tests/ballpit.test.mjs
node tests/ballpit-browser.mjs
npm run test:browser
```

ブラウザー検証はPC、スマホ縦横、320×568、740×360、プレイ途中の幅・高さ変更、全画面、同時タッチ、停止・再開、リセット、一覧への終了と再入場、強化・勝敗画面、記録保存を含みます。GitHub Actionsの既存ブラウザーテストにも組み込んでいます。

`?game=ballpit&debug=1` の場合だけブラウザーテスト用の `window.__ballpit` を公開します。通常のプレイでは公開しません。
