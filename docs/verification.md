## 追加・無効化・削除の実演

`npm run new-game -- platform-scaffold-check`で42本目を生成。本体・ビルド設定・一覧を変更せず、42枚目の表示・Phaser起動・加点をブラウザーで確認した。その後enabled=falseにしてindex.tsを削除し、41本のビルドが成功することを確認。最後にテスト用フォルダを削除して再ビルドした。提出時にはこの試験ゲームは含めない。

実行レポートとスクリーンショットは`.test-output/`。試験ゲームを含めたレポートは`scaffold-browser-report.json`、最終版は`browser-report.json`。

## 検証の範囲

全41本について全ステージ・全勝敗分岐までの自動プレイを行ったわけではない。旧ソースの温存、起動・共通操作の比較、変更したゲームの主要経路、既存のシューティング検証で回帰リスクを確認した。

iPhone/iPad/Androidの実機、Safari、Capacitor、Electron、Steamでの配布は未検証。旧ゲーム固有の設定と停止UIはそのゲーム側にも残る。ゲーム内に公開されていないスコアは共通バーに推測表示せず、元のゲーム画面で確認する。

新ランチャーはビルド出力のHTTP配信を前提とする。外部公開は実行していない。ファイル直開きやソースルートの直接公開は新しい起動手順には含まれない。
