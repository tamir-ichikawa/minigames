# おすすめゲームの管理

トップページとCollectionのゲーム一覧で、改修・実装・動作確認を重ねたゲームを「おすすめ」として先に表示します。ジャンルを選ぶと、おすすめ欄もそのジャンルで絞り込まれます。同じゲームを下の一覧に重複表示しません。

## 追加・並べ替え

対象ゲームの `games/<id>/manifest.json` に次の設定を追加します。

```json
"recommendation": {
  "order": 0,
  "reason": "反射するボールと強化で、3ウェーブ＋ボス戦。"
}
```

`order` は0以上の整数で、小さいほどおすすめ欄の上に並びます。同順位の場合は通常の `order`、次にIDで並びます。`reason` はカードに表示する短い特徴です。おすすめから外すときは `recommendation` ごと削除します。`enabled: false` のゲームはおすすめにも表示しません。

新規追加やファイルの更新だけで自動的におすすめにはしません。プレイ内容の改修と確認ができた段階で設定します。おすすめ未設定のゲームは従来の `order` 順で表示します。

## おすすめの選定

- マロの大冒険：全10ステージの冒険。新規公開に合わせて最上部に追加。
- INVADER ATTACK：3難易度のシューティング。新規公開に合わせて上部に追加。
- DDE / Dance：2曲・3難易度のリズムゲーム。新規公開に合わせて上部に追加。
- BALL＆PIT：試作から共通プレイヤーへ統合。戦闘・強化・ボス・保存・画面対応を検証。
- GOAT in ANGER：4人の隊員、3区間の進撃、障害物の迂回、移動・射撃の同時操作、画面対応を検証。
- STAR BOUNCE：7人の相棒・各3章の物語・必殺技に更新。保存、設定、共通プレイヤーとスマホ操作を検証。
- アストラ・パトロール：自機・敵編隊の改修と専用の描画検証。
- GOAT JUMP：横スクロール化、二段ジャンプとバー到達判定、子ヤギの救出演出。
- Enzine Rythm：演奏パートと曲の追加、リズム調整。
- 15パズル・星灯りタワー・早押しタップ：改良版を採用し、操作・スコア・停止・保存を検証。
- 反射神経テスト：Phaser版への移行、5回計測と記録保存を検証。

未公開の試作や別途改修中のゲームは、公開版への統合後に追加します。
