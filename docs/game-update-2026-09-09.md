## 既存ゲームのマージ判断

- **ケロの空中遺跡 / jump_v2**：スコアに応じた空の色、着地パーティクル、節目表示と任意の効果音を採用。到達可能な足場の固定設計、相対ドラッグ、固定60Hz、セーブキー、即リトライは維持。新版のランダム足場や一律の移動速度変更は採用しない。
- **小さな騎士の五連戦 / card_battle_v2**：五戦の進行表示、HPの警告色、防御中の発光、カード種別の色分け、直接リトライを採用。敵の行動予告、固有パターン、カード効果、成長選択、調整済みの難易度は維持。短い画面では進行表示と手札が収まるレイアウトに調整。
- **rhythm_mitan_v2**：元のリズム2本はEnzine Rythmの4レーン／1タップへ統合済み。新版のレーン発光、判定演出、音声例外処理は現行に同等機能があることをコードで確認。フレーム依存・ランダム譜面に戻さず、音源時刻同期、固定譜面、既存楽曲、設定を維持。重複ゲームは追加していない。
- バージョン指定のない旧サンプルで、既に改善済みのゲームは再インポートしない。

## 追加時に修正した問題

- ビートタップ：消費済みの直前拍を繰り返し採点する二重加点を防止。
- パターン記憶：成功・失敗演出中の入力をロックし、再提示後に入力を復帰。
- 数字順タップ：表示領域から必要な行数を確保し、320pxでも全数字を配置。
- ハノイ：初回描画の未初期化例外と、不正移動時の逆転した説明を修正。
- フルーツカット：一時停止・画面外リリース・タッチキャンセル時にドラッグ状態を解除。
- 反射神経：表示するミリ秒を整数化。どっちが多い：同数時はどちらでも正解という実装に説明を合わせた。
- 共通：ゲーム内の計時を一時停止対応の時計に接続し、Canvasゲームは固定60Hzに統一。
